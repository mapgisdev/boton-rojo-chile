# Prompt de fase 1 — Congelar baseline

Implementa la Fase 1 solo después de tener aprobada la auditoría.

Objetivos:
- convertir la lógica original en un baseline reproducible;
- crear tests unitarios y golden fixtures;
- comparar Python y GEE;
- corregir bugs técnicos sin alterar silenciosamente la metodología;
- documentar cualquier diferencia inevitable.

No incorpores todavía ML ni downscaling avanzado.
